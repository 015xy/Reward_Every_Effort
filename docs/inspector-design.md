# Inspector 设计记录

## 第一遍：从最终分数追到原始轨迹

用户是校准 Agent 奖赏、比较同一请求不同 rollout 的研究者与任务适配者。
参考三栏评估工作台的阅读方式：左侧选择数据，中间阅读原始轨迹，右侧解释
该条数据的计分过程。首屏保持轨迹与分数之间的对应关系。

右侧只保留一个完整流转图：

```text
             Gate
               ↓
             Base
               ↓
        Deduct     Bonus
               ↓
         Final reward
```

点击节点，在流转图下查看该阶段的实际计算。Base 内选择需求主体，再查看
查表结果、原始分、依赖影响、最终分与 judge 理由；分层平均和六行表按需展开。
Deduct 内选择检查组，再查看有成本的子项、理由、证据与指数曲线；完整子项
列表与公式按需展开。最终奖赏显示实际组合与截断，并提供扣分原因入口。
不把主体 DAG、所有公式或完整原始 JSON 同时铺满首页。

界面读取保存的记录，不运行第二套奖赏逻辑。正常路径显示真实 Base、扣分、
加分与最终值。Gate 直接路由时，用侧边连线连接 Gate 与最终奖赏；中间三个
阶段标注未运行。旧记录未保存 Gate、Bonus 或组合字段时显示“未记录”。
已配置但未启用的 Bonus，只有记录确实保存零值时才显示零。

## 第二遍：证据表达与窄屏修订

证据引用只是来源，不足以断言问题发生位置。`annotations` 显式区分问题与
支撑证据：问题所在消息使用实线红框和红色原文高亮，支撑证据使用黄色边框
和黄色原文高亮。每条判定只有一个“查看证据”入口，同时展开所有关联模块。
点击扣分默认定位问题，再考虑支撑证据；消息内保留对应理由。只有
`evidence_refs` 时，使用黄色标记“关联证据”，不将来源推断为问题。

中间轨迹保留用户请求、历史消息、工具调用、工具返回、最终回复与产物原文。
系统提示、任务上下文、工具参数等长内容按需展开。点击证据会展开对应内容
并在轨迹列中定位，避免离开当前数据或跳到外部页面。

桌面保留三栏。600–960px 将数据列表收为顶部横向选择，下方轨迹与分数仍
并排且独立滚动；599px 以下提供必要的“轨迹 / 分数”切换，默认展示分数。
点击证据自动切到轨迹。这避免小窗口退化成长文档、首屏看不到评分流程。
所有 grid 子项均可收缩，宽表格只在自己的视口内滚动。

| Token | 色值 | 用途 |
|---|---|---|
| ink | `#25324A` | 标题、内容与计算 |
| muted | `#778299` | 元信息与次级说明 |
| canvas | `#F7F9FC` | 数据选择与上下文背景 |
| blue | `#4C6FAF` | 当前阶段、选择与证据入口 |
| green | `#247A67` | 有效结果与 Gate 直接路由 |
| red | `#B94B48` | 明确问题、违规与其证据 |

正文使用系统字体，不加载远程字体、图标或资源。轨迹正文按下方示例样式
呈现；评分原因说明为 13–14px，数值使用等宽数位。英文和中文分别导出完整界面，输入、
判定理由、策略标识与证据原文不翻译。焦点清晰可见，减少动画设置得到尊重。

## 轨迹样式：遵循提供的 HTML 示例

轨迹区按用户提供的 case HTML 呈现，而不是将每条消息拆成独立标题与正文
卡片。角色标签位于消息块内部；用户、助手与工具分别使用 `#F4F7FC`、
`#F8FAFD`、`#F3F8F5` 底色。消息块为 8px 圆角、8px 垂直间距和
8px × 10px 内边距，正文为 12px / 1.55。轨迹使用系统字体，与示例一致。

思考、工具调用与工具返回使用同一套折叠结构：6px 圆角、细边框、
`#F4F3EF` 标题栏、白色原文区。调用栏直接显示工具名称；思考和返回栏
显示字符数。展开原文的最大高度为 280px，内容在模块内部滚动。正文直接
显示，长输入上下文和系统资料折叠。窄屏保持相同的紧凑消息样式。

示例中的具体任务文本、工具名称及公司资料不写入组件；内容由记录提供，
通过 `textContent` 安全显示。外部思考日志保留展示用途，与评分证据分离。
红黄证据状态只染色真实证据原文，不染色展示思考或系统资料。

## 验证

测试真实导出脚本的数据切换、Gate 路由、未运行与零值区分、精确标注、来源
不等于问题位置、缺失状态与极端指数参数；同时验证数据转义和两份语言导出。
实际浏览器验收桌面、约 673px 面板和 390px 视口，检查计分流程可见性、
局部滚动、节点选择及证据定位。
