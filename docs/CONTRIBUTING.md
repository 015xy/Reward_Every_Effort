# Development

Install `python -m pip install -e '.[dev]'`, edit the source pack, run
`python scripts/sync_pack.py`, `pytest`, and `ruff check src tests scripts`.
`ree doctor` validates the packaged default plan. Prompt changes require boundary
fixtures for no-tool completion, legal alternative strategies, honest failed
attempts, evidence gaps, and selective branch blocking.

Introduce new task rules in a TaskPack, retain source/version/fingerprint, and
measure live judge agreement before making claims about cross-task quality.
Changes to the Base table, qualification and aggregation are explicit policy
changes, distinct from removing domain-specific assumptions.

This repository is a clean local implementation. No private implementation,
credentials, production trajectories or enterprise-only dependencies are copied.
Use synthetic public examples in main. Before external publication review rights,
licensing and live calibration with the project maintainers.
